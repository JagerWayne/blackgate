Desktop, Start menu and window title-bar icons, one per application. Keep the subject centred with a little margin; it is shown as small as 16x16.

Every image: PNG, 128x128, transparent or solid background. Put the files in THIS folder; the game reads them by file name.
A file that is missing shows a grey rectangle instead, so you can add them one at a time.
